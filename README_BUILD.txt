TDT Viewer LFP Spectrogram v3
=============================

macOS ARM64
-----------
Ready ZIP: dist/TDT_Viewer_LFP_Spectrogram_v3_macOS_arm64.zip
After extracting, Control-click the app and choose Open on first launch.
The app is ad-hoc signed but not Apple-notarized.

Windows x64
-----------
Copy the entire Windows Build Kit to a Windows x64 computer with Python 3.12.
Double-click build_windows.bat. It creates the EXE folder and:
dist\TDT_Viewer_LFP_Spectrogram_v3_Windows_x64.zip

Keep the entire generated dist folder together; do not move only the EXE.
